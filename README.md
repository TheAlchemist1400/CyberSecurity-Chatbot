# CYBER HAWKS
# Cybersecurity Awareness Chatbot

This project is compiled using C#, it is designed to promote cybersecurity awareness by interacting with users and providing helpful information about staying safe online.

## Chatbot Part1
Features: voice interaction, visual enhancements, and user-friendly responses to create an engaging experience.

- Voice Greeting
Playes a WAV audio greeting when the application starts, using soundPlayer class.

- ASCII art display 
Displays a "cyber hawks" ascii logo when the program starts.

- Interactive chat system
Prompts user to enter their name
Personalises responses using the user’s name.
Supports continuous conversation until the user exits using while loops.

- Cyber security knowledge
Chatbot respondes to common syber topics such as: Passowrd safety, Phishing attacks, safe browings , maleware, who we are and what our purpose and goal

- INput validation
Handles empty or invalid input perfectly.
Provides fallback responses when input is not understood.

- Common support
typing help displays avaliable commands
typing exits the chatbot

- How to run the Project

git clone https://github.com/your-username/your-repo-name.git

3. Ensure:
